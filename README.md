# ai-template

対象プロジェクトで開発エージェントに「このディレクトリを ai-template の手順で初期化して」と依頼し、このREADMEと同じ版の [環境構築手順](SETUP.md) を読ませてください。エージェントはリンク先も取得してから作業を開始します。GitHub経由で読めない場合は同じコミットのローカルコピーの両ファイルを使用し、取得元と版を報告してください。

初期化の成果物は、対象プロジェクトのSpec Kit、開発規約、検証ハーネス、検証結果、引き継ぎです。利用者が説明するアプリは、必要な環境と検証方法を選ぶための入力です。機能の実装は、初期化結果を渡し、利用者が次の開発タスクを依頼してから開始します。
